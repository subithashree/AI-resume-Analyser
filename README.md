# AI Resume Analyzer

AI-powered Resume Analyzer using Python, Flask, NLP, Machine Learning, TF-IDF, Cosine Similarity, and Transformer-based AI Feedback.

## Features

- Resume Upload
- ATS Score
- Skill Extraction
- Missing Skill Detection
- AI Suggestions
- Dark Mode
- Database Storage

## Technologies Used

- Python
- Flask
- SQLite
- Bootstrap
- NLP
- Transformers
